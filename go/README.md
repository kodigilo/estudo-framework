# Go — como rodar

Sem Docker: usa só o Go instalado na máquina (`net/http`, biblioteca padrão).

## Rodar uma etapa

```bash
go run 01-servidor/main.go
```

Troque `01-servidor` pela pasta da etapa atual. Depois é só acessar `http://localhost:3002`.

Para parar, `Ctrl+C` no terminal onde o processo está rodando.
