# JavaScript — como rodar

Sem Docker: usa só o Node instalado na máquina (`http.createServer`, biblioteca padrão).

## Rodar uma etapa

```bash
node 01-servidor/index.js
```

Troque `01-servidor` pela pasta da etapa atual. Depois é só acessar `http://localhost:3001`.

Para parar, `Ctrl+C` no terminal onde o processo está rodando.
